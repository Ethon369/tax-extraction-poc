# 本轮需要讲清楚的内容

1. 第一版旧测试已经查看，不能用它证明改进后的泛化。因此另建26条新测试，同题比较两个适配器，不能直接将旧15条的百分比与新26条横比。
2. 数据改进聚焦缺失值与边界：抽取允许部分信息，未知字段用null；计算参数缺失或冲突则应fallback。0是明确数值，不表示未知。
3. 参数和提示词保持不变，但训练数据从40到88条、验证从8到24条、优化步数从50到110。改善不能简单归因于单一因素。
4. 模型返回错误工具调用即使被程序拦截，也仍是预测错误。模型指标看raw_output；拦截记录说明额外防线的表现。
5. 原文参数检查采用固定模式，可能错误拦截合法复杂表述。这不是通用语义理解，更不代表实际税务资格判断。
6. 结果报告必须保留改善、退化、仍失败案例及分子分母。小合成测试不代表真实企业数据，用户人工复核数据仍待完成。
